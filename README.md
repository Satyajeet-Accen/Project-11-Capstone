# Project 11: Infra Changes with Branching Policy

## Overview
This repository demonstrates the implementation of a Git branching strategy and Pull Request (PR) review policies for Infrastructure as Code.

## Objectives Achieved
* Created and utilized a feature branch (`feature/satyajeet-infra-update`) for infrastructure changes.
* Enforced branch protection rules on the main branch requiring PR reviews.
* Successfully merged an infrastructure update (S3 resource tagging) via a Pull Request.
